# Lost Lab

Static site, no build step.

```
index.html            the homepage (styles + intro animation included)
assets/logo_body.png  logo arch
assets/logo_eyes.png  logo eyes
```

- Intro animation timings mirror SplashScreen.tscn / SplashScreen.gd.
- Wordmark font is Jost (free Futura lookalike). Swap `--display` in index.html if you get a Futura web licence.
- Add project screenshots to `assets/` and replace each `[Screenshot]` with `<img src="assets/name.jpg" alt="...">`.
- Placeholders are in [brackets].
